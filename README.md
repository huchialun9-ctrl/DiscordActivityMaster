# Discord Activity Master (DAM)

Discord Activity Master (DAM) 是一套 Windows 本地處理程序管理與狀態模擬工具。透過在系統背景維持輕量虛擬進程並映射指定檔名，向 Discord 客戶端回報遊戲運行狀態，以累積遊玩時數、解鎖階級徽章，同時整合官方任務與排程功能。

---

## 主要功能

- **進程狀態模擬**：無需安裝遊戲本體，在背景執行微型進程並映射為目標遊戲檔名，向 Discord 回報運行狀態以累計時數。
- **官方清單與圖示同步**：串接 Discord 官方應用程式端點，自動取得支援遊戲資料庫與官方 CDN 圖示。
- **時數與等級試算**：輸入當前時數並設定目標階級門檻，自動推算剩餘時數差額、連續運作耗時與預計達成日期。
- **任務與活動追蹤**：監控 Discord Quests 任務狀態並發送進度信號，以取得活動限定獎勵。
- **指令互動排程**：定時向指定頻道發送斜線指令以領取機器人代幣或簽到，內建動態隨機延遲。
- **程序監控與自動化**：監控 Discord 客戶端連線狀態，提供多進程並發管理、異常重試與定時輪替機制。
